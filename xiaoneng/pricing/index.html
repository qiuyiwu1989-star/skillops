定价 FAQ

Early access 真的免费吗？有什么条件？

免费. 条件是愿意深度配合 —— 接入你真实的 skill 资产、给我们反馈、容忍 v0.x 的粗糙. 作为回报，你影响产品方向，并锁定后续优惠.

Pro 版"按资产规模"具体怎么算？

大致按被管理的 skill 数量分档（例如 ≤20 / ≤100 / 更多）. 具体分档和价格在 early access 阶段和用户一起敲定. 不会按调用量收 —— 这是管理工具，不是 API 网关.

我已经在用开源版，需要升级吗？

不需要. 开源版永久免费、功能完整（评分 + tier + 建议）. Pro 解决的是"托管 + 自动化 + 全局视角"，适合 skill 多到手动管不过来的团队.

和 Skill Hub 的 B2B 集成是一回事吗？

不是. Skill Hub for teams 卖的是方法论内容资产的集成；小能卖的是 skill 管理工具. 两个产品、两条线 —— 当然可以一起用.
