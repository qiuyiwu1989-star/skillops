Developer? (optional)_

You don't need this for everyday use. But if you build agents — SkillOps can be your agent's skill backend: one API key, and your agent pulls the skills you manage with a single curl.

Public skills can be pulled without a key. Read the docs →

# list all my skills curl https://skillops.tech/api/v1/me/skills \ -H "Authorization: Bearer xn_YOUR_KEY" # pull a single public skill (no key) curl https://skillops.tech/api/v1/skills/<handle>/<slug>
