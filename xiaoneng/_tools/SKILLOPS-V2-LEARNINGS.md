# SkillOps · 提升计划 v2 —— 把 Anthropic 方法论 + SkillNet 学过来

> 来源：Anthropic《Lessons from building Claude Code: how we use skills》(5 条经验) + 浙大 zjunlp **SkillNet**《Create, Evaluate, Connect AI Skills》(OpenKG)。
> 原则：**只学对的、守住身份** —— B 知识工作者 · 人在环 · 便携/跨 AI · 管理=核心护城河 · 不当运行时。
> 这 5 个主题都在**深化"管理(核心) + 评级(钩子)"**，强化护城河，不碰矛尖(运行)、不稀释 B。日期：2026-06。

## 不学的（守住身份，明确划界）
- ❌ 全自动 agent 编排/执行运行时（= 我们说过不做的"运行时"，且是 A territory，与 B/便携冲突）。
- ❌ 把产品做成研究框架 / benchmark 平台（SkillNet 那是学术定位，我们是产品）。
- 取其"方法"，不取其"形态"。

---

## 主题 1 · 技能：从"一坨文本" → 结构化技能（轻量文件夹模型）
- **学自**：Anthropic ②（skill 是文件夹 SKILL.md+references/scripts/examples + 渐进式暴露）、SkillNet（标准接口/模块化）。
- **现状差**：SkillOps 把技能存成单个 SKILL.md/提示词 blob。
- **做**：技能 = 主体（提示词）+ **可选结构化区块**（触发词/边界/示例/引用/脚本），渐进式呈现；**不强迫 B**（默认还是一段提示词，进阶才用结构）。
- **影响**：数据模型加结构 · 捕获/版本/调用（复制只贴主体+按需展开；MCP/插件暴露结构）。
- **优先级**：中（产品级、影响面大，分阶段；中期演进）。

## 主题 2 · SMS 评级升级（对齐方法论 + 接真实使用）★高
- **学自**：Anthropic ①（沉淀 gotchas/隐性知识）④（description=路由规则，自检）、SkillNet（执行级指标：成功率/效率/鲁棒）。
- **做**：SMS rubric 增三条锋利判据/信号：
  1. **隐性知识/坑密度**——奖励"老师傅经验/边界/反例"，惩罚复述常识。
  2. **路由自检**——"删掉正文只留触发描述，agent 还能不能知道何时调用？"做成"可调用性"维的具体打分锚点。
  3. **真实使用信号**——把调用次数→活跃度（将来→成功率）做成"动态分"，叠加静态 SMS（静态=潜力，动态=实证）。
- **卖点**：对外讲"**SMS 按 Anthropic + SkillNet 的方法论评分**"——信用层背书。
- **改动集中**：`scoring.mjs`（rubric/prompt）+ skill-coach 提示 + 控制台显示"动态分"。**低风险高价值。**

## 主题 3 · 技能关系图 / 轻组合（把 SkillNet 的 Connect 产品化）
- **学自**：SkillNet（Connect：层级组合 + 依赖图）。
- **现状差**：我们**评**了"可组合性"，但不让你**真组合**。
- **做**：先做**技能关系/图谱视图**（相关/fork 血缘/可组合）进控制台右栏（管理核心深化、低风险）；再考虑**轻组合**（A+B 组合成一次调用）。全自动编排留 A/第二幕。
- **优先级**：中（图谱视图先做）。

## 主题 4 · 自进化闭环（半自动·人在环）★高
- **学自**：SkillNet（执行→失败模式→技能更新）、Anthropic ⑤（用起来再说）、我们已有的 **skill-coach + 调用埋点 + 退役预警**。
- **做**：把已有拼图接成一条线 —— 使用反馈 → 控制台**主动提示**"这个技能该提分/已退化/没人用了" → **一键 coach** → 新版本 → 重评 → 趋势。**闭环，但每步人点头。**
- **诚实边界**：B 在别的 AI 里用技能，我们看不到"执行成功/失败"；所以信号先用"调用频次/分数趋势/久未更新"，成功率是以后（插件/MCP 能回传时）。
- **改动小**：coach + 埋点 + 生命周期 + 退役预警都已存在，主要是"主动提示 + 一键串联"。**最快见效。**

## 主题 5 · 与 SkillNet 互通（借开源对齐）
- **做**：扒 `zjunlp/SkillNet` 的**技能 schema + 评估指标**，对齐我们的数据模型(主题1) + SMS(主题2)；可能的话支持导入/兼容（生态友好、信用加成）。
- **优先级**：低-中（调研 + 对齐，穿插）。

---

## 执行顺序建议
1. **主题 4（自进化闭环）+ 主题 2（SMS 升级）** —— 都集中在已有的 coach/scoring/埋点上，低风险、高价值、直接强化"管理=护城河"。**先做这两个（协同：更好的评估喂更好的进化）。**
2. **主题 3（技能图谱视图）** —— 管理核心深化。
3. **主题 1（结构化技能）** —— 产品级中期演进，规划清楚再上（影响捕获/版本/调用/MCP/插件）。
4. **主题 5** —— 调研穿插。

> 一句话：这一轮是**把"管理 + 评级"做深做实**——SMS 更权威（对齐方法论）、技能会随用进化（半自动闭环）、技能间有关系（图谱）、技能本身更结构化。全部加固护城河，不动矛尖。
