⤓ 导出我的技能库

SkillOps 是中立的管理层 —— 你的技能跟着你走，不锁在任何一家。随时把整库带走、或交接给团队。
团队 / 治理（终局·建设中）
多人组织、角色权限、共享技能库（Library.owner）是下一个里程碑。在那之前，导出包就是团队交接的方式 —— 导出 JSON 发给同事，对方在控制台「招聘 → 粘贴」即可重建，评分/版本随附。
