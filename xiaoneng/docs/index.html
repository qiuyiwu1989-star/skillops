SkillOps 是你私人的 AI 技能库 —— 把好用的提示词 / 技能存进来，跟着你走，在任何 AI 里随手调用，越用越好。 可以理解成 AI 技能的 1Password：你的能力资产沉淀在一个中立、不被任何一家 AI 锁住的地方。这份文档讲清它的脊梁、三种调用方式、技能库怎么管，以及评分标准 SMS。

01这是什么

不是又一个 prompt 商店，而是「你自己的」技能库 —— 三件事：捕获 · 管理 · 调用。

你每天在 ChatGPT / Claude 里反复打磨提示词，但它们散落在聊天记录、笔记、收藏夹里，换个 AI 就丢了。SkillOps 把这些变成可管理的资产：

①捕获
CAPTURE

顺手把一个好提示词 / SKILL.md 存进库，自动 SMS 评级、自动归档。是建库的 on-ramp。

②管理
MANAGE

评分、版本、培训提分、组合关系、标签、导出。让库越用越值钱 —— 这是护城河。

③调用
INVOKE

在任何 AI 里随手调起：复制 / 浏览器插件 / MCP。调用是矛尖，让管理变得有意义。

④便携
PORTABLE

中立、不锁定 —— 技能跟着你走，随时一键导出整库带走。这是引力中心。

面向知识工作者（不只是开发者）：做战略、写作、创意、咨询、运营的人，都在积累自己的「打法」。SkillOps 让这些打法第一次有了可度量、可复用、可携带的形态。

生态位：Anthropic 做 Skill 格式标准，SkillOps 做你的私人技能库与管理层。就像 npm + 1Password —— 底层格式被巨头握住，「沉淀 / 评分 / 调用 / 便携」这层留给生态做，且跟着用户走、不当运行时。

03三种调用方式

技能跑在「你自己的 AI」里 —— SkillOps 只负责把技能取出来递给你，不替你执行、不锁定。

①复制到任何 AI
COPY · 通用

一键复制内容，粘进 ChatGPT / Claude / 任意对话框即用。地板最低、哪都能用，每次调用自动 +1 计数。

● 已上线
②浏览器插件
EXTENSION · B

装在 ChatGPT / Claude 网页：粘一次 API Key，输入框旁 ⚡ 直接调起任意技能，免复制粘贴。面向知识工作者。

◐ v0.1
③MCP
MCP · A

接 Claude Desktop / Code / Cursor：把整库接成工具，让 agent 自己 list / get / search。面向开发者 / agent。

◐ v0.1

插件与 MCP 用同一个 API Key。在控制台每个技能的「调用」页都能看到这三种方式的接入方法。

为什么不当运行时？有的竞品把技能放到自家服务器上执行 —— 短期方便，长期把你锁死、还掌握你的数据。SkillOps 反过来：技能在你选的 AI 里跑，库跟着你走。中立和便携，是我们不动摇的立场。

04管理你的技能库

控制台 = 你的技能管理中心。这是产品的核心护城河 —— 库越用越好，靠的就是这一层。

全生命周期
LIFECYCLE

招聘 → 评级 → 迭代提分 → 发布 → 归档。每个技能都有清晰的状态与「下一步」。

版本 + 维度 diff
VERSIONS

每次保存留一版，可查看 / 回滚 / 对比；提分后能看到是哪一维涨了多少。

评分 + 小能培训
SCORE · COACH

SMS 逐维评级；小能定位最弱维度、重写 SKILL.md 帮你冲段位。

组合关系图
GRAPH

给技能连边：可组合（compose_with）/ 依赖（depend_on），把库变成一张能编排的图。

标签 · 搜索 · 批量
ORGANIZE

标签 / 集合分组，按分数 / 调用 / 最近排序，多选批量公开 / 归档 / 导出。

一键导出（便携）
EXPORT

把整库导成 SKILL.md 文件夹（.zip）或可重导的 .json。随时带走、交接团队。

个人用不用登录、本地就能开始（数据存在你这台浏览器）。需要上云 / 公开 / 给 agent 调用时，再用一个账号 key 创建云端账号 —— 无需邮箱密码。

05SMS 评级体系

SMS = Skill Management Standard · 衡量一个技能成熟度的标准化度量，是建库的钩子。

市面上的 skill / GPT / prompt 库都没有质量度量。SMS 把成熟度拆成 4 支柱 × 10 维（可理解 / 可执行 / 可工程 / 可信赖与价值），每维 0–10 分、总分 100，由引擎自动评估 + 关键资产人工校准。rubric 持续迭代 —— 当前看重是否沉淀了隐性经验与坑（gotchas）、以及触发设计能否让 agent 在对的时机准确召唤（路由自检）。完整方法论见 SMS 标准 →

03可执行性

产出是否达资深从业者水准、沉淀了隐性经验与坑，而非复述常识或套模板。

08团队 / 治理

个人用永久免费、不用登录。团队 / 组织是终局，正在建设。

多人组织、角色权限、共享技能库（Library.owner）、质量门禁 —— 这一层需要一套鉴权 / 多租户基建，是独立的里程碑，我们不画假 UI。在那之前，「一键导出」就是团队交接的方式：导出整库或选中的技能，发给同事在控制台重建，评分 / 版本随附。

09FAQ

这和直接用 ChatGPT / Claude 有什么区别？

AI 是「运行时」，SkillOps 是「你的能力库」。你打磨的好提示词不该锁在某个聊天记录里 —— 存进库后，它可评分、可迭代、可组合，并且在任何 AI 里都能调用，换平台不丢。

它和那些 skill 市场 / 闭源平台的区别？

有的平台把技能放自家服务器执行 + 变现，本质是运行时 + 锁定。SkillOps 是相反的一极：不当运行时、不锁定 —— 技能在你选的 AI 里跑，库随时可导出带走。中立和便携是立场，不是功能。

「便携」具体意味着什么？

控制台一键把整库导成标准 SKILL.md 文件夹（.zip）或可重导的 .json。你的资产不依赖我们存活 —— 这是我们给「跟着你走」的硬承诺。

评级是 AI 打的还是人工打的？

AI 自动评分 + 关键资产人工校准。引擎按 4 支柱 × 10 维逐维评估，S 段核心资产额外人工复核。标准版本化迭代、公开可质疑。

我的技能不是 Claude 格式，能用吗？

SMS 维度是格式无关的 —— 评的是技能的内在质量。只要能整理成结构化描述（用途、触发、步骤、输出），ChatGPT 提示词 / 通用 prompt / 自定义 agent 都适用。
