SkillOps / 接入

接入你的 AI_

把你的技能库接进任何 AI —— 远程 MCP（agent 自己 list / get / search / 跑技能链）和浏览器插件（ChatGPT / Claude 网页输入框旁 ⚡ 一键调起）。技能跑在你自己的 AI 里，SkillOps 只把技能递过去，不替你执行、不锁定。

API Key · 用于手动连接和浏览器插件

到 控制台 顶栏 「API Key」→「＋ 生成 key」，复制那串 xn_…。新生成的 API Key 可以从列表再次复制。使用下方 OAuth 连接器时无需填 Key。

① 远程 MCP OAuth 或 API Key

给 Claude / Cursor 等 MCP 客户端用。接上后 agent 能直接调你的技能库、甚至顺着关系跑整条「技能链」。

MCP URLhttps://skillops.qiuyiwu.com/api/mcp

已有配置使用 https://skillops.tech/api/mcp 时，带 API Key 的请求仍会转发到同一套 SkillOps。新建连接或重新授权时请使用上方新地址。

个人 AGI 如需按版本读取个人技能中心的正式发布包，继续使用 https://mcp.qiuyiwu.com/mcp。

Claude.ai 网页版 / Claude 桌面版（连接器 · OAuth · 免填 key）✨

设置 → Connectors / 连接器 → 「Add custom connector」→ 名称随意、URL 填上面那个 → 保存后点 连接 / Connect → 跳到 SkillOps 授权页（需先登录 skillops.qiuyiwu.com）→ 点「授权」即可。不用手动填 API Key，走标准 OAuth。

Cursor

编辑 ~/.cursor/mcp.json：

{ "mcpServers": { "skillops": { "url": "https://skillops.qiuyiwu.com/api/mcp", "headers": { "Authorization": "Bearer xn_你的key" } } } }

Claude Code（一条命令）

claude mcp add --transport http skillops https://skillops.qiuyiwu.com/api/mcp \ --header "Authorization: Bearer xn_你的key"

Claude Desktop（经 mcp-remote 桥接）

编辑 claude_desktop_config.json：

{ "mcpServers": { "skillops": { "command": "npx", "args": ["-y", "mcp-remote", "https://skillops.qiuyiwu.com/api/mcp", "--header", "Authorization: Bearer xn_你的key"] } } }

接上后对 AI 说「列出我的技能」「用 jtbd-analyzer」「跑 X 的技能链」即可。每次 get_skill / run_chain 都记为 🟢 真调用（不是软复制）。
偏好本地 stdio？仓库 mcp/ 里也有一份；远程版省去 clone，推荐。

② 浏览器插件 ChatGPT / Claude 网页

在 ChatGPT / Claude 网页的输入框旁加一个 ⚡，点一下把技能注入对话框，免复制粘贴。

⤓ 下载插件（.zip）
下载并解压 上面的 zip，得到一个 extension 文件夹。
Chrome / Edge 打开 chrome://extensions，右上角开 「开发者模式」。
点 「加载已解压的扩展程序」，选刚解压出的 extension 文件夹。
点插件图标 → 粘 API Key → 保存。
打开 chatgpt.com 或 claude.ai → 输入框旁的 ⚡ → 选技能 → 注入。

v0.1（还没上架商店，所以走「加载已解压」）。注入失败会自动兜底成复制 —— 哪个站不行告诉我们，改一下选择器即可。支持站点：chatgpt.com / chat.openai.com / claude.ai。
