# skillops · 技能人事部（HRD）

> 把每个 AI 技能当员工管：入库 → 落户 → 盘点 → 评级 → 图谱 → 培训 → 绩效 → 退役。
> 造物云出品 · © 邱懿武 · **SMS 标准与方法论公开发表**

一个可直接安装的 **agent skill**。装上之后，你的 AI 就成了你的技能人事专员：你说人话，它跑系统，向你汇报，你拍板。

## 它解决什么

你的技能（SKILL.md / 提示词 / 工作流）散落在各个项目、各个目录：**没有花名册，没有版本，坏了没人知道，好坏没有标准。** 这个包给你一套完整的人事管理：盘点、身份、评级、提分、退化预警、可逆退役。

**不搬家、不托管、不当运行时**——技能真身永远是你自己的文件（file-as-truth），技能永远跑在你自己的 AI 里。

## 安装

**Claude Code / Claude Desktop**
```bash
unzip skillops-skill-v1.0.0.zip -d ~/.claude/skills/
```
装完得到 `~/.claude/skills/skillops/`。重开会话即可用。

**其他 agent（Cursor / OpenClaw / 自建 agent）**
解压到你的 agent 读取技能的目录即可；本包不依赖任何特定 agent 平台。核心资产是 `SKILL.md` + `references/`（纯 Markdown）+ `scripts/`（零依赖 Node）。

**要求**：Node ≥ 18（只用内置模块，无需 npm install）。

## 上手三步

1. **初始化** —— 对你的 AI 说：「初始化一下技能人事部，我的命名空间用 `<你的名字>`」
2. **盘点** —— 「扫描一下我的技能库」→ 得到花名册 + 体检（无户口/分身/分歧）
3. **评级** —— 「审计一下 XX 技能」→ 10 维评级 + 提分建议

之后就用人话使唤它：
> 「造一个技能」「帮 XX 提分到 A」「哪些技能在退化」「哪些技能该下线」「团队能力盘点」

## 内容

| 文件 | 是什么 |
|---|---|
| `SKILL.md` | 岗位说明书：角色、九个动作路由、行为规约 |
| `references/sms.md` | **SMS v2.0 完整标准**（4 支柱 × 10 维 × 100 分，S/A/B/C/D 段位） |
| `references/playbooks.md` | **九个 play × 八个 HR 模块**的完整执行步骤 |
| `references/methodology.md` | 技能 HRD 方法论（为什么这样管、五层架构、六条铁律） |
| `references/cli.md` | CLI 手册 + 可选钩子配置 |
| `scripts/` | 零依赖 CLI（盘点/落户/体检/周报/评级） |

## 隐私

一切数据留在本机（`~/.skillops/`）。**技能内容不上传任何服务器。** 评级直连你自己配置的 LLM 端点，花你自己的额度。

## 关于标准

**SMS（Skill Management Standard）公开发表**，欢迎第三方实现、引用与批评。不同团队可调整权重与门槛，但请保留维度定义与锚点阶梯——这样分数才可比。
