# V4.2 分层市场与快速调用

## 目标

让技能在正式企业认证之前也能形成真实供给，但不牺牲安装和生产使用的可信边界。

## 三级状态

### 已收录 `indexed`

- 来源身份稳定且可追溯；
- 公开元数据完成隐私裁剪；
- 可以搜索和进入详情页；
- 不复制技能包，不宣称可以调用或安装。

### 可调用 `callable`

- 满足已收录要求；
- 基础格式与安全检查通过；
- 有明确、短小、可公开的调用模板和任务示例；
- 用户可以复制调用模板，在自己已有的 AI 工作环境中发起任务；
- 不等于平台执行，不等于技能包分发，也不等于企业生产认证。

### 企业认证 `certified`

- 可再分发许可明确；
- 完整技能包与包审计当前；
- SMS、Eval 与双人独立终审均绑定当前包；
- Registry Release 当前且未撤回；
- 才能标记可安装，并进入企业生产分发。

## 公开目录投影

每项使用稳定 `publisher/name` 身份和固定 `slug`，不得暴露 Candidate ID、本地路径、CAS 存储位置、审核人身份或运行时输入输出。

可调用项允许包含一个公开 `invocation`：

```json
{
  "mode": "copy_text",
  "text": "请使用某技能处理下面的任务：",
  "examples": ["具体任务示例"]
}
```

这里的 `text` 是发布者授权公开的调用模板，不是 Eval 或用户运行时 Prompt。

## 状态升级与降级

- `indexed -> callable`：格式、安全和调用说明通过。
- `callable -> certified`：许可、完整包、Eval、终审与 Registry Release 全部当前。
- 任何当前证据失效时立即取消 `certified` 和安装资格。
- 来源或安全状态失效时，`callable` 降为 `indexed` 或撤回。

## 首批发布

首批 3 个造物云自有技能以 `callable + source_only` 发布：需求简报器、生产事故快诊、判断库架构。三者已通过完整包安全扫描；许可证正式声明、Eval 与双人终审仍待完成，因此不可安装。
