# 006: V3.4 独立技能详情页

## 要什么

把市场弹窗证据速览升级为每个 approved listing 都拥有独立、可分享、可深链访问的中文详情页。市场卡片主按钮进入详情页；弹窗可以保留为快速预览，但不得再承担详情页角色。

## 用户闭环

`市场发现 → 技能卡片 → 独立详情页 → 证据判断 → 来源或受控部署`

## URL 与构建契约

- 详情 URL 使用 `/skills/<listing-id>/`，以不可变 candidate id 作为路由键，避免中文名称变化导致链接失效。
- 静态构建为每个 approved listing 生成 `market-preview/skills/<listing-id>/index.html`。
- 同时生成详情数据 `market-preview/data/skills/<listing-id>.json`，数据只能来自 `CandidateStore.listListings()`。
- 页面不得读取候选池、未批准内容或运行时 store。
- 直接打开详情 URL、浏览器刷新和从市场卡片进入都必须可用。

## 页面信息架构

### 首屏

- 中文主题与中文说明作为主信息。
- 英文原名、来源坐标、版本作为辅助信息。
- SMS 总分/段位、Eval 状态、许可、安全、包完整性形成判断摘要。
- 展示返回市场、查看来源和安装资格操作。

### 主体

- 适用场景、分类、标签、输入/输出说明。
- SMS v2 十维分数、理由和证据。
- Eval 测试集、环境、成功率或明确 pending。
- 来源、签名、commit、指纹、版本。
- 许可、安全发现、人工审核事件。
- 完整包状态、文件数量、安装边界和 deploy 说明。
- 相关技能仅基于同分类或标签，不伪造个性化推荐。

## 中文与可信边界

- 中文名称/说明优先；自动翻译必须标注待校对并保留原文。
- SMS 是静态质量潜力，Eval 是运行实绩，分别展示。
- `source_link_only` 不显示正文或安装按钮。
- 非完整包不得提供直接安装。
- 页面不得展示虚假下载量、五星、评论或成功率。

### A · 详情页 UI

- 新增详情页模板、样式和客户端渲染。
- 实现中文首屏、证据分区、移动布局和返回市场。
- 文件边界：`market-preview/detail.*` 与必要的 UI 测试夹具。

### B · 静态路由构建

- 扩展构建器，为 approved listing 生成详情 JSON 与静态 HTML 入口。
- 清理本次构建遗留的过期生成路由，但不得删除非生成内容。
- 文件边界：`market-preview/build.mjs`、`market-preview/serve.mjs` 与构建测试。

### C · 独立验收测试

- 黑盒验证每个 listing 有独立 URL/JSON、非 approved 不泄漏、深链刷新可用。
- 验证中文主标题、英文别名、SMS/Eval、安装边界和无虚假指标。
- 文件边界：新建独立 V3.4 测试文件与测试夹具，不修改生产实现。

### D · 主线集成

- 市场卡片进入独立详情页，保留快速预览入口。
- 合并相关技能、中文本地化与真实 listing 数据。
- 完成桌面、390px、直接深链、刷新和 console 验收。

## 不做什么

- 不接生产站点或冻结中的 `api-server/`、`xiaoneng/`。
- 不执行第三方技能，不伪造 Eval，不自动安装。
- 不在本版实现账号、评论、收藏、支付或作者后台。
